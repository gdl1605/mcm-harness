# 数据管道实现 Memo：{{TITLE}}

> 本文解释共享数据管道怎样实现当前计划，并暴露限制和隐式状态。以下问题是最低责任，不是代码目录或实现方式白名单。

## 实现范围与所有权

说明唯一共享管道实现者、允许修改范围、未修改的原始材料和本版实现对应的数据计划/契约版本。

## 运行入口与环境

给出从原始附件开始的命令、依赖、配置、参数、随机性、外部资源和预期输出位置。指出无法自动化或仍需人工确认的环节。

## 分层与数据血缘

解释 raw → staging → canonical → analytical 的实际代码路径、对象转换和版本关系。逐个关键输出说明来源与生成步骤。

## 核心实现决策

说明主键、时间、单位、连接、缺失、零值、重复、异常、筛选和派生量怎样实现，以及如何对应预处理计划。不得用模型表现作为共享处理依据。

## 代码与测试索引

列出入口、模块、测试、配置和运行文档。说明测试覆盖什么、没有覆盖什么，以及哪些断言只是机械不变量。

## 决定性、幂等与版本

说明相同输入能否得到相同输出、重复运行是否安全、旧版本如何保留、失败后从哪里恢复。

## 已知限制、争议与禁止下游用途

明确哪些字段或视图仍是 proxy、暂用解释或不适用于某些时点/总体；哪些使用方式会造成泄漏或越过数据契约。

## 实现中框架外发现

记录代码或数据运行暴露的新结构、异常和前半程风险，即使它不属于原计划。

## 交给独立 reviewer 的重点

指出最希望被推翻的假设、最脆弱步骤、复现入口和最小人工抽样位置。不要替 reviewer 宣布通过。

# 独立模型验证交接：{{TITLE}}

> 本交接授权后续模块可使用的结果、主张和条件，不宣称模型无条件正确。以下是最低责任，不是语义 schema 或输出上限。

## 验证范围、源版本与未覆盖内容

索引题意、路线、数据、建模、官方要求、validation map 和实际验证单元；说明未能验证内容。

## 逐问可引用结果与主张

链接精确结果表、模型/run 版本、claim disposition 和可直接使用的表述；不从其他旧 run 选更好看数字。

## 有条件、暂不可引用与被反驳主张

完整保留适用范围、假设、误差、失效条件、禁止过度表述和否定证据。

## 独立复现、数学实现与实验证据摘要

链接 V1 review、高影响 docket/probe/response/decision 和原始输出，说明它们分别支持了什么。

## 题间接口、不确定性与失效传播

说明整体题链审查结果、可用接口版本、条件性输入和上游变化的下游影响。

## 保留信息暴露与独立性边界

索引 exposure ledger，说明哪些证据已成为开发信息，后续不得再声称未见。

## 回滚、修正、重验与旧版本

索引上游变更请求、已完成局部修正、新证据复验、被替换版本和仍暂停使用的产物。

## 后续绘图与章节材料授权

指定可用结果表/字段/单位/范围、允许支持的 claim、必须披露的限制和不允许使用的候选。

## 未决争议、用户判断点和任务之外的新发现

保留无区分证据、预算不足、需人类选择的争议和可能改变后续表述的新信息。

## 停止边界

验证模块到此停止。尚未执行：论文级绘图、章节材料包、答卷生成和正式论文写作。

# 摘要压力测试

这不是摘要填空模板。它用于检查一版摘要是否让评委在不读正文时获得正确的答案地图。

## 隐藏正文测试

只保留标题、摘要和关键词，请另一位读者复述：

- 论文把全题拆成了哪些决策或判断；
- 每问的主答案是什么；
- 哪些结果是定量证据；
- 哪个方法解决了哪个真实困难；
- 本文相对直观基线增加了什么。

无法被复述的内容不是“写得不够华丽”，而是摘要中的任务、证据或答案缺失。

## 删除测试

逐个删除模型名：如果摘要含义几乎不变，说明模型名没有承担信息，应改写其职责或删除。

逐个删除数字：如果删去后无法判断方案差异、边界或性能，数字应保留；如果数字没有比较口径或无法影响判断，应移出摘要。

逐句检查：如果某句只适用于任何数学建模论文，例如“结果表明模型具有良好适用性”，应以本题证据替换或删除。

## 反向核验

- 摘要中的每个关键数字能否在正文定位到表、图或计算口径？
- 摘要中的每个方法能否在正文定位到输入、输出和验证？
- 摘要中的“创新”是否对应一个本题难点及其实际收益？
- 摘要是否隐瞒了会改变主结论的重要条件？

## 信息排序

优先级通常是：

1. 题目要求的主答案；
2. 支撑答案的关键数值或比较；
3. 处理核心困难的方法职责；
4. 必要的适用条件；
5. 次要算法细节。

这只是信息选择原则，不规定段落数量和句式。

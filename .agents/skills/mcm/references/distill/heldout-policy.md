# 独立评测与语料隔离策略

## 当前状态

2025 C 题题面、C023、C132、官方 C 题评讲和全国评阅材料已经用于本轮 skill 修订。2025 因此不再是 held-out 数据，只能作为已暴露的诊断与回归语料。

任何继续把 2025 称为“未见测试年”的报告都不可信。

## 两类评测必须分开

### 已暴露回归

用途：检查改动是否丢失已经确认的关键能力，例如：

- 识别重复测量与个体差异；
- 区分预测值与首次达标时间；
- 让分组服务于时点或风险决策；
- 从多个情景中给主方案与触发条件；
- 审查高准确率背后的标签、划分和判定规则；
- 从首页发现模型清单压过主答案的问题。

回归通过只说明没有明显退化，不说明具有泛化能力。

### 真正 held-out 评测

用途：检验 skill 在未见题目上的任务理解、路线选择、答案组织和审稿判断。

测试题应满足：

- 修订 skill 时没有阅读题面、数据、优秀论文或官方评讲；
- 在测试输出冻结前不透露参考方案；
- 与当前语料至少在领域、观测结构或交付形式上存在差异；
- 有足够信息核验任务理解和答案质量。

## 冻结流程

1. 记录待测 skill 版本或提交。
2. 选择未暴露题目并记录来源与暴露状态。
3. 只提供题面和允许使用的数据。
4. 让 skill 独立完成：
   - 任务拆解与答案形状；
   - 数据风险；
   - 主路线与必要备选；
   - 验证计划；
   - 论文证据结构或评委向审稿。
5. 冻结全部输出。
6. 再公开官方评讲、优秀论文或专家参考。
7. 对照核心判断，不按模型名或句式相似度比较。
8. 只在完成整轮测试后修订 skill，防止逐题追答案。

## 评测维度

- 是否识别了题目真正要求的决策或判断；
- 是否尊重观测单位、时间、分层、代理标签和约束；
- 主模型是否解决关键困难；
- 是否产出题目要求的答案形状；
- 验证是否可能改变或限定结论；
- 多问接口是否连贯；
- 首页和正文是否让主答案与证据可定位；
- 是否避免模板化、模型堆叠和虚假确定性。

## 评分方式的边界

自动评测可以检查文件、引用和明显遗漏，但语义能力应由自然语言理由和反例判断。不要以固定关键词、段落数量、图表数量或模板字段命中率代替评估。

## 防泄漏记录

每个评测案例记录：

- 题目标识与来源；
- skill 冻结版本；
- 首次暴露时间；
- 是否看过参考答案；
- 输出冻结时间；
- 对照后发现的偏差；
- 是否因此修改 skill。

如果暴露状态不清楚，该案例只能算回归，不能算 held-out。

## 一句话原则

已见语料用于追溯和防退化；未见语料才用于证明迁移。

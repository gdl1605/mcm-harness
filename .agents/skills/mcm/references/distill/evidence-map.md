# 规则证据索引

## 证据等级

- **官方明示**：赛题、规则、官方评讲或全国评阅材料直接说明。
- **跨年共性**：多个年份和论文反复出现。
- **同题互证**：同一题的多篇论文或论文与官方评讲相互支持。
- **单篇观察**：只能作为候选做法，不能升级为默认规则。
- **设计推断**：为运行或阅读压力测试建立的可检验假设，必须明确不是官方规定。

## 2025 两篇论文的互补观察

### C023

支持：

- 首页直接暴露分组边界、推荐时点和判定数量；
- 混合效应模型与重复测量结构相对应；
- 最终把模型输出转成可执行答案。

不能支持：

- 混合效应模型适用于所有关系题；
- 特定 BMI 边界或阈值可迁移；
- 开发网页工具是获奖必要条件。

### C132

支持：

- 多模型可以按任务模块分工；
- 复杂模型需要诊断、对比和解释路径；
- 预测、分组、风险和分类应由接口连接。

不能支持：

- 元学习、深度学习或 LightGBM 是国奖默认配置；
- 模型越多越好；
- 单一高准确率足以证明判定可用。

## 官方 C 题评讲带来的修正

旧规则中“分组 + 预测 + 优化”仍过于表面。官方材料要求更具体地追问：

- 分组为何能降低风险或改善决策；
- 最优时点对应何种达标概率与错误代价；
- 测量误差是否让建议需要安全边际或复检；
- 离散检测怎样影响首次达标时间的观测；
- 个体差异怎样进入总体方案。

因此，skill 不应只识别模型族，而应识别观测机制与答案形状。

## 低证据做法

下列做法只能在数据和题意明确需要时启用：

- 默认深度学习或元学习；
- 默认 CVaR；
- 默认遗传算法；
- 默认熵权/TOPSIS/AHP；
- 默认中心化对数变换；
- 默认将复杂模型写成创新点；
- 默认使用固定论文骨架或摘要公式。

## 新规则纳入条件

新增规则前至少回答：

1. 它来自官方明示、跨年共性还是单篇观察？
2. 它约束的是语义行为还是表面措辞？
3. 它能否在一个未见题目上被反证？
4. 它是否会诱导模型堆叠或模板化？
5. 它替代了哪条旧规则，还是只增加噪声？

只有能改善未见题目决策质量的规则才进入主 SKILL.md。
